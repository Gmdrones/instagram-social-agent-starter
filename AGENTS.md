# Agent instructions
This is a local-first, public starter. Never access private machine directories outside the project or disclose credentials, personal data, contacts or files. Use official Meta APIs only. Do not scrape Instagram, auto-follow arbitrary profiles, send unsolicited DMs, bypass limits, or claim a message was sent when it was only drafted. Use the local CLI to manage niche-specific lead research entered by a user, generate editable drafts and test API connectivity. Require properly verified webhooks and platform permission checks before any live messaging feature. Never promise zero blocks. Explain that Maestri terminal provisioning is manual in this release.
